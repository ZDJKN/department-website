# 点石成金 · 部门网站预览

这是用于查看页面样式、团队组织结构和项目案例的只读预览。包含前端源码、公开内容快照及页面使用的图片，不需要数据库或后端服务。

## 本地运行

使用 Node.js 22.13+：

```sh
npm ci
npm run check
npm run build
npm run preview
```

打开终端给出的地址。支持首页、案例筛选和详情、团队逐层展开、成员介绍与对应项目。使用 hash 路由，复制成员或案例链接即可直接分享。

## 修改与发布

- 前端页面：`apps/web/src/`；视觉样式：`site.css`、`team-explorer.css`。
- 公开内容：`content/site.json`；图片：`media/`。图片路径使用相对于站点根目录的 `media/文件名.webp`。
- `main` 为已认可版本；新方向从 `codex/design-*` 分支开始，提交 PR 查看差异。PR 自动检查与构建，合并 main 后自动部署 Pages。PR 不会自动产生独立预览链接。
- 仓库 Settings → Pages 选择 GitHub Actions。工作流文件为 `.github/workflows/pages.yml`。
- 已发布版本用标签保留；回退可对 main 执行对应的 revert，再由工作流发布。

此预览没有后台编辑功能。完整工程和私有资料由本地项目单独维护；本仓库不含原始 PPT、聊天、内部经营资料、管理员凭据或数据库。

页面素材仅用于本项目展示；未另行授予图片、品牌标识及人物照片的再使用许可。

## 2026-11-04 更新
